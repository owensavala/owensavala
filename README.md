Perjalanan teknologi saya berawal dari bangku **SMK jurusan Teknik Komputer dan Jaringan (TKJ)**—terbiasa merakit CPU, instalasi sistem operasi, dan mengonfigurasi jaringan LAN fisik. Lulus pada tahun 2020, saya melanjutkan studi di **Teknik Informatika Universitas Khairun (Unkhair) Ternate**, memperluas pondasi rekayasa perangkat lunak dari C++ hingga arsitektur web modern.

Sejak masa perkuliahan, saya aktif menggabungkan teori akademis dengan **eksekusi lapangan kerja nyata**:
* 🛰️ **Starlink & MikroTik Hotspot Innovation:** Mengembangkan **StarTik Hotspot**, solusi manajemen voucher satelit Starlink & MikroTik RouterOS untuk memecahkan keterbatasan CGNAT di pulau-pulau 3T.
* 🖥️ **Lab Computer Automation:** Membangun **LabMaster**, sistem otomasi Wake-on-LAN massal dan penguncian internet MikroTik Exam Guard untuk persiapan lab ujian ANBK/CBT sekolah.
* 🏛️ **Government Web Engineering:** Di semester 7, dipercaya merancang dan membangun sistem aplikasi web dinas pemerintahan (nilai proyek Rp 25 juta) secara mandiri selama 5 bulan sebelum era generator AI populer.
* 📡 **Island Network & Starlink Deployment:** Memasang dan mengonfigurasi internet satelit Starlink di sekolah-sekolah kepulauan, merancang sistem voucher WiFi, mengimplementasikan **Load Balancing** untuk kestabilan ujian 50+ laptop secara simultan, serta memelihara lab komputer sekolah untuk ujian nasional (ANBK).
* 🛠️ **Cross-Island Field IT Specialist (MSB Solutions):** Menjalankan jasa servis panggilan laptop, PC, printer, dan jaringan menyeberangi lautan antar-pulau dari Ternate menuju Bacan, Kayoa, hingga Subaim (ganti LCD, keyboard, baterai, upgrade RAM & SSD, hingga network sharing).
* 🤖 **AI & Autonomous Agents:** Mengembangkan otomasi pintar berbasis Google Gemini AI dan GitHub Actions untuk ekstraksi data publik dan pengiriman notifikasi instan.
